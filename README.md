## 📜 Random Quote Generator

This is a simple React.js application that displays motivational and philosophical quotes from various notable figures. With each click, a new random quote is shown.

### ✨ Features

- Random quote generation from a predefined list.
- Smooth and centered layout with responsive styling.
- Stylish background with an engaging quote box.
- Credits included in the footer.
